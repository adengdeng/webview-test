OpenWebDialog 測試頁

情境1：GET + 內開 webview (inApp=Y)
情境2：GET + 外開 Safari (inApp=N)
情境3：POST + 內開 webview (inApp=Y)
情境4：POST + 外開 Safari (inApp=N)
情境5：inApp 空白（預設應走內開）
情境6：url 為空（應直接 return，不開任何頁面）

URL Scheme 測試 (tdccmvote://)

情境7：外開連結 tdccmvote://openBrowser?url=XXX
情境8：開啟 PDF tdccmvote://openPdf?url=XXX
情境9：登出 tdccmvote://logout

開戶 URL 測試 (jumpToStock / jumpToCredit)

這兩個 marker 是原生端在攔截 WebView「導覽」時，用 containsString 比對整段 URL 字串觸發的， 不是走 postMessage，也不需要帶任何參數 —— 只要導覽的網址中含有該字串即可。
情境10：開股票戶 !!jumpToStock!!
情境11：開複委託/信用戶 !!jumpToCredit!!
